# TG-мод — удалённые сообщения, ID, поиск и т.д.

Юзербот на [Telethon](https://github.com/LonamiWebs/Telethon). Работает от твоего аккаунта,
поэтому подходит **любой** клиент Telegram (официальный, на айфоне, Android, ПК). Сам мод должен быть
постоянно запущен: на ПК, сервере/VPS или на Android через Termux.

## Что умеет

| Функция | Как работает |
|---|---|
| 🗑 **Удалённые сообщения** | Текст и медиа (фото, видео, голосовые, кружки, файлы) приходят тебе в «Избранное» |
| 📦 **Сводка при массовом удалении** | Если в чате удалили сразу много сообщений (по умолчанию больше 5), придёт одно сообщение со списком, а не поток уведомлений |
| 🧵 **Темы (форумы)** | В уведомлениях видно, в какой теме группы было сообщение, и есть ссылка прямо на тему |
| ✏️ **Изменённые сообщения** | Присылает «Было / Стало», хранит всю историю правок |
| ⏳ **Самоуничтожающиеся медиа** | Фото и видео с таймером сохраняются, копия сразу приходит в «Избранное» |
| 👁 **Белый / чёрный списки** | Следить только за нужными чатами или исключить шумные |
| 🔎 **Поиск** | Полнотекстовый поиск по всему кэшу, включая удалённые сообщения |

## Команды

Пишешь сам в любом чате, мод заменяет твоё сообщение ответом. `.help` показывает актуальный список.

| Команда | Что делает |
|---|---|
| `.id` | ID чата и твой; ответом на сообщение — ID автора, сообщения и откуда переслано |
| `.id @user` | ID пользователя или канала |
| `.info` | ID, юзернеймы, телефон (если виден), DC, статус, «о себе», общие чаты, метки |
| `.deleted [N]` | Последние N удалённых сообщений в этом чате |
| `.history` | Ответом на сообщение: все его прошлые версии |
| `.search слово` / `.s слово` | Поиск по кэшу. Флаги: `-тут` только этот чат, `-уд` только удалённые, `-30` число результатов (до 50) |
| `.ignore` / `.unignore` | Добавить чат в чёрный список или убрать из него |
| `.watch` / `.unwatch` | Белый список: если он не пуст, мод следит **только** за этими чатами |
| `.lists` | Показать оба списка |
| `.stats` | Статистика кэша |
| `.modules` | Загруженные модули |

Команды списков без аргумента действуют на текущий чат. Можно указать другой чат: `.ignore @username` или `.ignore -1001234567890`.

Поиск не различает регистр и «ё/е» и ищет по началу слова: `.s елк` найдёт «Ёлку».

## Установка на ПК

### Windows
1. Установи Python с https://www.python.org/downloads/ и при установке **обязательно поставь галочку
   «Add python.exe to PATH»**.
2. Получи `api_id` и `api_hash` на https://my.telegram.org → **API development tools**.
3. Скачай папку `tg-mod` и дважды кликни **`start.bat`**.
   При первом запуске он сам всё установит, потом спросит `api_id`, `api_hash`, номер телефона и код
   из Telegram (и пароль 2FA, если включён). Дальше вход запоминается.
4. Окно не закрывай: пока оно открыто, мод работает. Если мод упадёт, он сам перезапустится через 10 секунд.

**Автозапуск вместе с Windows:** нажми `Win + R`, введи `shell:startup` и нажми Enter. В открывшуюся
папку положи ярлык на `start.bat` (ПКМ по файлу → «Создать ярлык» → перетащи ярлык туда).

### Linux / macOS
```bash
cd tg-mod
./start.sh
```

Лог работы пишется в `data/mod.log`.

## Настройки (`config.json`)

Файл создаётся при первом запуске. Новые настройки (например, из новых модулей) дописываются в него автоматически.

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `prefix` | `"."` | Префикс команд |
| `log_chat` | `"me"` | Куда слать уведомления: `"me"` = Избранное, или `@username` / ID своего приватного канала |
| `whitelist` | `[]` | ID чатов: если не пуст, мод следит только за ними (удобнее менять командой `.watch`) |
| `blacklist` | `[]` | ID чатов, которые мод игнорирует (удобнее менять командой `.ignore`) |
| `notify_deleted_in` | `["private", "groups"]` | Где сообщать об удалениях: `private`, `groups`, `channels` |
| `notify_edited_in` | `["private"]` | Где сообщать об изменениях |
| `batch_threshold` | `5` | Больше стольких удалений за раз — одна сводка (`0` = всегда по одному) |
| `batch_delay` | `3` | Сколько секунд собирать удаления в одну пачку |
| `save_media` | `true` | Скачивать медиа заранее (после удаления скачать его уже нельзя) |
| `max_media_mb` | `20` | Не скачивать файлы больше этого размера |
| `save_self_destructing` | `true` | Сохранять медиа с таймером |
| `ignore_bots` | `true` | Не следить за сообщениями ботов |
| `keep_days` | `7` | Сколько дней хранить обычные сообщения в кэше (удалённые хранятся всегда) |
| `disabled_modules` | `[]` | Модули, которые не нужно загружать, например `["edits"]` |

## Модули

Вся функциональность разложена по файлам в `modules/`, и каждый файл подключается автоматически:

| Файл | Что внутри |
|---|---|
| `cache.py` | Запоминает сообщения, скачивает медиа, определяет темы форумов |
| `deleted.py` | Уведомления об удалении, сводки, `.deleted` |
| `edits.py` | Уведомления об изменении, `.history` |
| `ids.py` | `.id`, `.info` |
| `search.py` | `.search` |
| `lists.py` | Белый и чёрный списки |
| `system.py` | `.help`, `.stats`, `.modules` |

**Свой модуль:** создай новый файл в `modules/` и перезапусти мод, основной код трогать не нужно.
Готовый шаблон лежит в `modules/_example.py`: скопируй его, например, в `modules/hello.py`.
Файлы, имя которых начинается с `_`, не загружаются. Если в модуле ошибка, мод запишет её в лог
и продолжит работать без него.

```python
"""Мой модуль"""                      # первая строка — название в .help и .modules
from telethon import events
from core import command, handler, config_defaults, ctx, esc

config_defaults(hello_text="Привет")  # своя настройка, появится в config.json

@command("hello", help="поздороваться", usage="[имя]")
async def cmd_hello(event, arg):
    await event.edit(f"{esc(ctx.cfg['hello_text'])}, {esc(arg)}!")

@handler(events.NewMessage(incoming=True))
async def on_message(event):
    ...
```

Из `core` также доступны `ctx.store` (база), `ctx.client` (клиент Telethon), `send_log()`
(отправить в лог-чат), `is_tracked()` (учитывает списки), `on_startup` (фоновая задача) и др.

## Тесты

Офлайн-тесты с заглушками вместо Telegram: ни аккаунт, ни интернет не нужны.

```bash
python -m unittest          # Linux / macOS, из папки tg-mod
```
На Windows дважды кликни `test.bat` (после того как хотя бы раз запускал `start.bat`).

Тесты проверяют базу (поиск, ё/е, миграцию старых баз, очистку), уведомления об удалении и сводки,
темы форумов, списки, правки и все команды. Запускай их после изменений в коде.

## Важно знать

* Мод видит только сообщения, пришедшие **пока он запущен**. Удалённое до запуска не восстановить.
* `config.json` и папка `data/` содержат ключи и сессию твоего аккаунта. **Никому их не передавай**,
  в git они не попадают (см. `.gitignore`).
* Юзерботы формально разрешены, но при спаме командами или массовых действиях Telegram может
  ограничить аккаунт. Мод только читает и пишет тебе в «Избранное», так что риск минимальный.
* Если ты сам удалил чужое сообщение «у себя», мод тоже сочтёт его удалённым: Telegram это никак не различает.
