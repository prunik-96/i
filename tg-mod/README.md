# TG-мод — удалённые сообщения, ID и т.д.

Юзербот на [Telethon](https://github.com/LonamiWebs/Telethon). Работает от твоего аккаунта,
поэтому подходит **любой** клиент Telegram (официальный, на телефоне, ПК). Сам мод должен быть
постоянно запущен: на ПК, сервере/VPS или на телефоне через Termux.

## Что умеет

| Функция | Как работает |
|---|---|
| 🗑 **Удалённые сообщения** | Когда собеседник удаляет сообщение, текст и медиа (фото, видео, голосовые, кружки, файлы) приходят тебе в «Избранное» |
| ✏️ **Изменённые сообщения** | Присылает «Было / Стало» |
| ⏳ **Самоуничтожающиеся медиа** | Фото и видео с таймером или «просмотр один раз» сохраняются, копия сразу приходит в «Избранное» |
| 🆔 `.id` | ID чата и твой ID; в ответ на сообщение ещё ID автора, ID сообщения и откуда переслано |
| ℹ️ `.info` | ID, юзернеймы, телефон (если виден), DC, статус, «о себе», число общих чатов, метки (Premium/бот/SCAM) |
| 📜 `.deleted [N]` | Последние N удалённых сообщений в текущем чате |
| 📝 `.history` | В ответ на сообщение: все его прошлые версии |
| 📊 `.stats` / `.help` | Статистика кэша и список команд |

Команды пишешь сам в любом чате: мод заменит твоё сообщение ответом.

## Установка

1. Получи `api_id` и `api_hash` на https://my.telegram.org → **API development tools**.
2. Установи Python 3.9+ и зависимости:
   ```bash
   cd tg-mod
   pip install -r requirements.txt
   ```
   **Termux (Android):** `pkg install python git && pip install telethon`
3. Запусти:
   ```bash
   python main.py
   ```
   При первом запуске он спросит `api_id`, `api_hash`, номер телефона и код из Telegram
   (и пароль 2FA, если он включён). Дальше вход сохраняется в `data/session.session`.

## Настройки (`config.json`)

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `prefix` | `"."` | Префикс команд |
| `log_chat` | `"me"` | Куда слать уведомления: `"me"` = Избранное, или `@username` / ID своего приватного канала |
| `notify_deleted_in` | `["private", "groups"]` | Где сообщать об удалениях: `private`, `groups`, `channels` |
| `notify_edited_in` | `["private"]` | Где сообщать об изменениях |
| `save_media` | `true` | Скачивать медиа заранее (после удаления скачать его уже нельзя) |
| `max_media_mb` | `20` | Не скачивать файлы больше этого размера |
| `save_self_destructing` | `true` | Сохранять медиа с таймером |
| `ignore_bots` | `true` | Не следить за сообщениями ботов |
| `keep_days` | `7` | Сколько дней хранить обычные сообщения в кэше (удалённые хранятся всегда) |

## Важно знать

* Мод видит только сообщения, пришедшие **пока он запущен**. Удалённое до запуска не восстановить.
* `config.json` и папка `data/` содержат ключи и сессию твоего аккаунта. **Никому их не передавай**,
  в git они не попадают (см. `.gitignore`).
* Юзерботы формально разрешены, но при спаме командами или массовых действиях Telegram может
  ограничить аккаунт. Мод только читает и пишет тебе в «Избранное», так что риск минимальный.
* Если ты сам удалил чужое сообщение «у себя», мод тоже сочтёт его удалённым: Telegram это никак не различает.
